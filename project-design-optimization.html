Project

Optimization of a mechanical design parameter space

Exploring and optimizing a multi-parameter design space to balance stiffness, mass, and cost.

Role: Modeling & optimization · Context: Design study for a mechanical component
Design of experiments Surrogate modeling Optimization MATLAB / Python
← Back to project list

Overview

This project focused on understanding how a set of design parameters influenced the performance of a mechanical component and then using that understanding to suggest improved designs. Full high-fidelity simulations or tests for every parameter combination were not practical, so a more efficient strategy was needed.

I created a simplified but representative model, ran a structured set of simulations, and built surrogate models that approximate key performance metrics across the design space.

Design of experiments

I defined the parameter ranges and used design of experiments techniques to select a manageable set of sample points. This provided good coverage of the design space without requiring an exhaustive grid.

At each sample point, performance metrics such as stiffness, mass, or stress were computed using analytical models or fast simulations.

Surrogate modeling & optimization

Using the sampled data, I built surrogate models (polynomial response surfaces or other regression-based approximations) that map design parameters to performance metrics.

These surrogates were then used in a multi-objective optimization routine to identify designs that balance competing goals. The most promising candidates were checked again with higher-fidelity analysis.

Results & impact

The optimization study revealed trade-offs between stiffness, mass, and cost and highlighted a set of candidate designs that met the project's constraints. The methodology provides a repeatable way to explore design spaces efficiently and can be adapted to other components with similar needs.
