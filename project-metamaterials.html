Programmable mechanical metamaterials for vibration and shock absorption

A bistable cellular panel whose response is set by which cells buckle. The inverse problem — reading a target force response and returning a buckling pattern that produces it — is solved with a physical reservoir computer.

Programming a panel by choosing where it buckles

The metamaterial is a planar cellular panel arranged on a staggered lattice. Every cell is a bistable element that sits either unbuckled or buckled, so the state of the panel is a binary pattern. Under compression it snaps through a sequence of local buckling events, and the pattern it ends up in determines how much energy the panel absorbs and how it responds to vibration and shock. That is what makes it programmable: the same physical panel has many mechanical responses available to it, selected by which cells have snapped.

The forward direction is easy enough — pick a pattern, simulate, get a force–displacement curve. The useful direction is the inverse: given a target response, which pattern produces it? That is the problem this project attacks, and the answer turns out to depend on something the data itself tells you about what a force curve can and cannot reveal.

Figure 1 — The staggered lattice

Figure 1. The panel is a 19×11 grid in which a position is an addressable cell only when r + c is even — a quincunx sublattice of 105 cells interleaved with 104 structural voids, with six cells on even rows and five on odd rows. Two cells are coupled when they are neighbours under the offset set {±1, ±5, ±6, ±11} on the linear index: two cells across, the four diagonals, and two rows away. Node degree runs from 3 at a corner to 8 in the interior, mean 6.86. One cell is highlighted with its neighbours. This adjacency is what defines a connected cluster of buckled cells, and it is used both to label the data and to grow synthetic patterns.

What a force curve can actually tell you

The dataset is a set of simulated compression runs — 23,915 raw, reduced to 20,787 unique after removing 3,128 exact repeats, so that identical runs cannot appear in both training and test sets. Each run gives a pattern, a 200-point force curve normalised per run, and a peak force between 5.7 and 50.4.

Before anything else, the physical curve has to be put back together. The supplied curves are normalised, which throws away amplitude — and amplitude is exactly what carries the strongest signal in the data: the correlation between peak force and number of buckled cells is −0.884. Rescaling by the peak recovers it to a median relative error of 0.4%.

The decisive measurement came next. The curve reports how many cells buckled and how fragmented the buckled region is — but not where on the panel it sits. Centroid coordinates are recovered at R² ≤ 0.06, and the row and column occupancy profiles are predicted no better than by knowing the cell count alone. So predicting 105 bits directly collapses onto the prior. The statistics, by contrast, are genuinely recoverable. That single finding sets the architecture of everything downstream.

Figure 2 — The signal

Figure 2. Every run has three phases: a loading ramp, a buckling plateau where the slope collapses as cells snap through, and a second loading ramp. The plateau sits near samples 76–147 on average, drifting run to run (onset correlates −0.56 with peak force). The curve is resampled to 105 points — one per cell — before being fed to the reservoir. Right: what the signal carries. Extent and fragmentation are recoverable; location is not. Hence the design decision to predict pattern statistics and synthesise a matching pattern, rather than predict the pattern cell by cell.

The pipeline

Rather than predict the pattern, the model predicts three descriptors: the cell count n, the cluster count κ under the lattice adjacency, and the largest cluster L. Each is a separate regression, and a pattern matching them is synthesised afterwards.

The reservoir is a chain of 20 bistable viscoelastic oscillators — the same class of element as the metamaterial cell it is being asked to describe, and governed by the same viscoelastic constitutive law as my von Mises truss work. It is used purely as a fixed nonlinear feature map: the force curve drives it, the internal states are recorded, and only a linear readout is ever fit. The reservoir itself is never trained.

Figure 3 — From curve to pattern

Figure 3. The 105 resampled force values are presented one at a time, each held for one pseudo-period while the chain evolves under fixed-step RK4. A 200-pulse warm-up is run and discarded so recording starts from a settled operating point. The recorded feature is the pulse-mean position, which suppresses the carrier ripple; concatenating current and previous state gives 4200 features. A separate 411-dimensional raw feature vector is formed alongside, because the reservoir sees only the normalised curve and is amplitude-blind by construction — amplitude carries extent, reservoir dynamics carry fragmentation. The readout is kernel ridge in dual form with an unpenalised intercept, on the sum of two trace-normalised RBF kernels.

Figure 4 — The reservoir, runningrunning

Figure 4. The chain being driven by a force curve, one pulse per input sample. Each oscillator obeys q̇ = v, v̇ = De²(3q² − q³ − 2q − λz − Rℓ + Y₀(1 + aiu)cosΩt), ż = v/(1−β) + q − z, with De = 1.0, λ = 2.22, β = 0.543, R = 2.97, Y₀ = 1.07, Ω = 3.00. Amber nodes are the ones the random input mask actually drives; a homogeneous mask is forbidden because it makes the chain mirror-symmetric and halves the usable state rank. Below, the pulse-mean states that become the features.

Synthesising a pattern

Because location is not recoverable, cell placement is governed by a prior rather than by the curve. The count-conditional occupancy prior is the empirical frequency with which each cell is buckled among training runs of similar cell count — the only spatial information the synthesiser uses, and it comes from the training patterns, not from the force response.

Two rules keep the cluster count intact while the pattern grows. Seeds exclude a two-hop neighbourhood, not one hop: two seeds sharing a common neighbour would merge on the first growth step. And growth only accepts frontier cells adjacent to no other cluster. Several restarts are run and the sample closest to target is kept, so repeated application to the same curve yields different patterns from the same constrained family — the output is a sample from a distribution, not a point estimate.

Figure 5 — The island algorithm, liverunning

Figure 5. The real algorithm running on the real lattice. Watch it seed κ clusters with two-hop exclusion, grow each along its frontier, then top up to reach the cell count. Colour is cluster identity; thick outlines mark seeds. The panel reports target against realised. Set n = 59, κ = 9 — the dataset mean — and it hits both exactly. Push both to their extremes together and it falls short, because 96 cells in 17 separate clusters leaves too few free cells to keep them apart; the feasibility condition ⌈n/κ⌉ ≤ L ≤ n − (κ−1) is necessary but the packing is the real constraint.

What it achieves

At matched linear readout the reservoir features beat the raw curve on every fragmentation descriptor — cluster count R² of 0.66 against 0.58 — so the dynamics do real work. At matched nonlinear readout an RBF kernel on the raw curve roughly matches it, which is worth stating plainly: the reservoir is one way to realise a useful nonlinearity, not the only one. But the combination of raw and reservoir kernels beats either alone, reaching R² = 0.759 on cluster count. Cell count is best predicted from the raw features, since the reservoir is amplitude-blind.

The synthesised patterns track the predicted statistics closely — correlations of about 0.96 on cell count, 0.85 on cluster count and 0.81 on largest cluster. More importantly they have the right topology: the realised cluster count spans the true range, whereas a direct per-cell regression always produced a single connected blob. The synthesis trades a fraction of a percent of per-cell bit accuracy for patterns that are physically plausible.

Per-cell accuracy is a pessimistic metric here: a physically valid pattern scores wrong whenever it is not the exact recorded one, and many distinct patterns produce nearly identical curves. The right validation is whether a synthesised pattern reproduces the measured force response, which requires a forward model — the natural next step.
